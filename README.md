# Titan V3

Titan V3 is a Ghana draughts engine and, in later phases, a browser-based
competitive play and training platform.

Phase 1 contains only the rules engine. It intentionally has no UI.

## Run the tests

Node.js 24 or newer can execute the erasable TypeScript used by the engine:

```sh
npm test
```

The product requirements and rule decisions are defined in `TITAN_SPEC.md`.
